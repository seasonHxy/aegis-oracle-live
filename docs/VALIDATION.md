## 构建提示与评估

Rust Clippy 使用 `-D warnings`，通过且无警告。Foundry lint 仍有非阻断提示，不能将 Solidity 构建描述为“零警告”：

- `block-timestamp`：用于源时间、有效期及过期检查，是预言机时效设计的一部分；区块时间受验证者和链规则影响，不应解释为精确的外部时钟。
- `unused-return`：包括预期 revert 的测试调用，以及仅使用部分返回字段的消费路径。
- 其余包括公开字段命名、导入方式、测试字面量和验签 calldata 读取中的内联汇编提示。本轮未为清理风格提示而改变公共接口。
- 沙箱内 Foundry 无法写入用户目录的签名缓存会打印环境警告；编译及测试退出码均为 0，未修改用户目录权限。

这些检查不替代独立安全审计。新增测试未发现需要修改业务逻辑的失败。

## 本机编译缓存说明

本机默认 Cargo registry cache 由 root 拥有，验收使用 `CARGO_HOME=/private/tmp/aegis-cargo` 构建，未修改原缓存权限。项目本身不依赖该绝对路径。若你的环境也遇到缓存写权限问题，可使用自己的可写缓存：

```bash
export CARGO_HOME="$PWD/state/cargo-cache"
cargo build --locked
```

已经编译好的本地演示可直接运行 `python3 scripts/demo.py --no-build`。
