# 项目说明

## 概述

Aegis Oracle Live 是一个 Rust + Solidity 多源价格预言机 MVP，从 Coinbase、Kraken 和 Bitstamp 获取真实 USD 成交价，经过数据校验、聚合和风控后，用签名报告更新 EVM 合约。

## 技术设计

项目解决的是“链上合约如何消费带时效检查的外部价格”。链下 Rust 负责三个交易所的专用接口解析，统一价格精度和成交时间，并验证独立来源数量、异常价格和价格跳变。链上 Solidity 不直接访问交易所，而是验证 EIP-712 报告的签名、链与合约域、序号和有效期，再提供 checked price 接口。

项目重点处理三个工程问题：第一，使用交易所成交时间，不能用 HTTP 接收时间掩盖旧行情；第二，用固定精度和明确的 USD 交易对避免单位混用；第三，交易签名后先持久化再广播，重启后处理原交易，避免盲目重发。

项目有独立的确定性测试与联网检查：本地模拟异常数据、服务限流及交易中断；实网脚本采集真实公开行情并留下带时间的证据。演示合约只做抵押估值，不实现完整借贷。当前是单签名者、本地链验证的 MVP，不把验签等同于价格真实性或去中心化共识。

## 运行与验证

1. `cargo run --locked -- --config config/live-eth-usd.json`：显示真实来源和源时间。
2. `python3 scripts/demo.py --live-data`：真实数据上本地链，读取抵押估值。
3. `make check`：重现确定性测试，展示来源故障及健康状态恢复。
4. `make live-smoke`：保存当前实网观察；来源失效时记录失败状态。
